# Cafe Management System

A personal learning project built using Spring Boot to understand enterprise application development concepts.

## Purpose

This project was created to learn and practice:

* Spring Boot
* Spring Security
* JWT Authentication
* OAuth2 Authentication
* Role-Based Access Control (RBAC)
* Spring Data JPA
* MySQL
* REST APIs
* Angular Integration

## Features

### Authentication

* User Registration
* User Login
* JWT-Based Authentication
* OAuth2 Login

### Authorization

* Admin Role
* Vendor Role
* Student Role

### Cafe Management

* Menu Management
* Order Management
* Vendor Approval Workflow
* User Management

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* MySQL

### Frontend

* Angular

### Tools

* Git
* GitHub
* Postman

Entity → Repository → Service → Controller
